# SureFlap Mikrochip Katzenklappe Connect

## Kurzurteil

Die SureFlap Mikrochip Katzenklappe Connect richtet sich an Haushalte, die mehr benötigen als eine klassische Mikrochip-Katzenklappe. Sie erlaubt individuelle Ein- und Ausgangsrechte je Tier, kann mit der Sure Petcare App verbunden werden und liefert Aktivitätsdaten. Für sämtliche App-Funktionen ist jedoch ein Sure Petcare Hub erforderlich.

**Geeignet für**

- Mehrkatzenhaushalte
- individuelle Zutrittsregeln
- automatische Sperrzeiten
- App-Benachrichtigungen
- Fernverriegelung

**Weniger geeignet für**

- Haushalte ohne Interesse an App-Funktionen
- möglichst geringe Anschaffungskosten
- Nutzer ohne Platz für einen Hub
- sehr große Katzen, die mehr Durchgang benötigen

# Das Connect-System erklärt

```
Katze
   │
Mikrochip-Klappe
   │
Sure Petcare Hub
   │
Router
   │
Sure Petcare App
```

Die Mikrochip-Erkennung funktioniert lokal an der Klappe. Fernsteuerung, Push-Mitteilungen, Statistiken und Änderungen per App werden erst über den Hub bereitgestellt.

---

# Was unterscheidet Connect?

## Gegenüber der Standard-Version

- individuelle Ausgangsrechte
- App
- Fernverriegelung
- Aktivitätsprotokoll
- Sperrzeiten

## Gegenüber DualScan

DualScan erlaubt bereits individuelle Richtungen je Tier. Connect ergänzt zusätzlich die App-Anbindung und die Verwaltung über den Hub.

- Hub-Kosten vergessen.
- Durchgang nicht mit der Katze vergleichen.

# FAQ

## Funktioniert die Klappe ohne Internet?
Ja. Die Mikrochip-Erkennung funktioniert lokal. App-Funktionen benötigen jedoch Hub und Internet.

## Funktioniert sie ohne WLAN?
Ja, solange keine App-Funktionen genutzt werden.

## Kann ich den Hub später nachrüsten?
Ja.

## Können mehrere Smartphones genutzt werden?
Ja, über die App-Verwaltung des Haushalts.

## Was passiert bei leerer Batterie?
Die Batterie sollte rechtzeitig ersetzt werden. Vor dem Kauf sollte das Verhalten laut Hersteller geprüft werden.

## Welche RFID-Anhänger sind kompatibel?
Kompatible SureFlap-RFID-Anhänger können alternativ zum implantierten Mikrochip genutzt werden.
