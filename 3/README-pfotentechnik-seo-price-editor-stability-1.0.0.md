# PfotenTechnik SEO Price Editor Stability 1.0.0

Der Fix verhindert, dass die automatische Synchronisierung der Produktpflege
gerade bearbeitete Preisfelder zurücksetzt. Ungespeicherte Eingaben bleiben
außerdem bei einem Astro-Dev-Reload innerhalb desselben Tabs erhalten.

## macOS / Linux

```bash
node 3/pfotentechnik-seo-price-editor-stability-1.0.0.mjs
```

## Windows PowerShell

```powershell
node .\3\pfotentechnik-seo-price-editor-stability-1.0.0.mjs
```

Optional zunächst nur prüfen:

```bash
node 3/pfotentechnik-seo-price-editor-stability-1.0.0.mjs --check
```

Optional ohne vollständigen Build:

```bash
node 3/pfotentechnik-seo-price-editor-stability-1.0.0.mjs --no-build
```
