# PfotenTechnik Home Card & Sticky Polish 13.2.0

Der Patch verbindet auf der Startseite Bild und Text wieder zu einer einzigen
Karte und reduziert die mobilen Abstände der Top-Empfehlungsleiste.

## macOS / Linux

```bash
node 3/pfotentechnik-home-card-sticky-polish-13.2.0.mjs
```

## Windows PowerShell

```powershell
node .\3\pfotentechnik-home-card-sticky-polish-13.2.0.mjs
```

Nur prüfen:

```bash
node 3/pfotentechnik-home-card-sticky-polish-13.2.0.mjs --check
```

Ohne vollständigen Build:

```bash
node 3/pfotentechnik-home-card-sticky-polish-13.2.0.mjs --no-build
```
