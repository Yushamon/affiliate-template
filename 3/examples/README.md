# Beispiele für Dateinamen

Lege fertige Bilder nach diesem Schema ab:

```text
<vergleichsslug>-editorial-hero.webp
```

Beispiele:

```text
gps-tracker-hunde-editorial-hero.webp
beste-futterautomaten-editorial-hero.webp
beste-trinkbrunnen-editorial-hero.webp
mikrochip-futterautomaten-editorial-hero.webp
```

Das globale Fallback heißt:

```text
default-editorial-hero.webp
```

In diesem Release-Paket sind bewusst keine generierten Beispielbilder enthalten. Dadurch bleiben Repository-Größe, Rechtekette und visuelle Freigabe kontrollierbar.
